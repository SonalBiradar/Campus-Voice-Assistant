#Campus Voice Assistant

## Project Overview
The JSPM University Campus Voice Assistant is a multilingual voice-based application designed to help students access campus-related information easily.

It supports English, Hindi, and Marathi, making campus information accessible to students who are more comfortable communicating in their preferred language.

## Problem Statement
Students sometimes face difficulties finding campus locations and accessing basic college information. This project provides a simple voice-based solution to make campus navigation and information retrieval easier.

## Technologies Used
- Python
- Streamlit
- SQLite
- Speech Recognition
- Google Text-to-Speech (gTTS)
- HTML and CSS (UI styling)

## Key Features
- Voice-based interaction
- English, Hindi, and Marathi language support
- Speech recognition
- Text-to-speech responses
- Campus location and information assistance
- Simple and user-friendly interface

## Project Structure
- `app.py` – Main application code
- `style.css` – Application styling
- `campus.db` – SQLite database (sample data only)
- `requirements.txt` – Python dependencies
- `README.md` – Project documentation

## Installation and Setup

1. Clone this repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Navigate to the project folder:
   `cd CampusVoiceAssistant`

3. Create a virtual environment:
   `python -m venv venv`

4. Activate the virtual environment:
   `venv\Scripts\activate`

5. Install dependencies:
   `pip install -r requirements.txt`

6. Run the application:
   `streamlit run app.py`
